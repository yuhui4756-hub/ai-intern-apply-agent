# 浏览器扩展采集 MVP

更新时间：2026-08-05

本扩展用于 V0.2：在用户正常登录的 Edge/Chrome 中采集当前岗位页或搜索结果页，并发送到本地简历投递 Agent。

## 功能

- 采集当前岗位：读取当前页 URL、标题、正文可见文本和链接，发送到本地应用，创建岗位并分析。
- 采集搜索结果：读取当前页 URL、标题、正文可见文本和链接，发送到本地应用，创建搜索记录和候选岗位列表。

当前不做：

- 自动回复 HR。
- 自动投递。
- 上传或发送简历。
- 读取 Cookie、密码、验证码、请求头、本地存储、隐藏字段或截图。

## 安装

1. 确认本地应用已启动：

   ```powershell
   .\.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   ```

2. 打开 Edge 扩展管理页：

   ```text
   edge://extensions
   ```

3. 打开“开发人员模式”。
4. 选择“加载解压缩的扩展”。
5. 选择本仓库中的 `browser_extension/` 目录。

Chrome 也可以使用同样方式加载：

```text
chrome://extensions
```

## 使用

### 采集当前岗位

1. 在招聘平台打开岗位详情页。
2. 点击浏览器工具栏里的“简历投递 Agent 采集器”。
3. 点击“采集当前岗位”。
4. 扩展会返回“打开本地结果”，点击后进入岗位详情页。

### 采集搜索结果

1. 在招聘平台打开搜索结果或岗位列表页。
2. 点击浏览器工具栏里的“简历投递 Agent 采集器”。
3. 点击“采集搜索结果”。
4. 扩展会返回“打开本地结果”，点击后进入候选岗位列表。

## 常见问题

### 提示无法连接本地应用

确认本地服务正在运行，并且浏览器可以打开：

```text
http://127.0.0.1:8000
```

### 没有识别到候选岗位

可能原因：

- 当前页面不是搜索结果页。
- 页面上的岗位链接尚未加载出来。
- 招聘平台改了链接结构。

可以先滚动页面，确保岗位列表已经出现在页面里，再重新采集。

### 为什么不是直接读取普通 Edge 当前页

普通 Edge 页面不能被本地后端稳定读取。扩展运行在用户当前登录的浏览器里，能避免重复登录，同时不需要读取 Cookie 或平台密码。
